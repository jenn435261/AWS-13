        If This Is An Emergency

        • Stay calm. Move to a safe location away from immediate hazards.
        • Conserve phone battery: lower screen brightness and close other apps.
        • This board updates from devices on the local network — check back for new alerts.
        • Share verified information only. Do not spread rumors.
        • If you can reach official services, call local emergency numbers.
        • Help others nearby if it is safe to do so.
